# 🏡 Dwelling – Premium Real Estate Platform

Dwelling is a modern, responsive real estate web application built with **React.js** and **Vite**. It showcases curated apartments, villas, lofts, and independent houses with a premium user experience, elegant UI, and smooth interactions.

> Designed with a strong focus on visual hierarchy, typography, responsiveness, and polished UI/UX.

---

## ✨ Features

- 🏠 Premium property listing cards
- 🔍 Advanced property search & filtering
- ❤️ Wishlist management
- 🖼️ Property image gallery & carousel
- 📍 Property details page
- 📱 Fully responsive design
- ⚡ Fast performance with Vite
- 🎨 Modern and clean UI
- ♿ Accessible keyboard navigation
- 💎 Smooth micro-interactions

---

## 🛠️ Tech Stack

- React.js
- Vite
- React Router DOM
- Tailwind CSS
- Framer Motion
- React Icons
- Context API

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/....
```

### 2. Navigate into the project

```bash
cd dwelling
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

The application will be available at:

```
http://localhost:5173
```

---

## 📦 Build for Production

```bash
npm run build
```

Preview the production build:

```bash
npm run preview
```
